# BUILD REQUEST — AGRIGUARD AI

Build a complete, polished, responsive AI-powered agricultural web application called “AgriGuard AI”.

## 1. PRODUCT PURPOSE

AgriGuard AI is an AI-powered agricultural decision-support platform designed to help farmers convert real-world field conditions into simple, actionable farming guidance.

The application must act as a real-time bridge between:

Farmer Input + Crop Image + Location + Live Weather + Crop Growth Information

and:

Disease Detection + Climate Analysis + Risk Assessment + Treatment + Irrigation Guidance + Crop Care + Harvest Prediction + Future Alerts.

The application should feel like a real professional agricultural technology product suitable for a hackathon demonstration.

Do NOT make it look like a generic dashboard or basic CRUD application.

The website must be visually impressive, intuitive, modern, cinematic, responsive, and functional.
